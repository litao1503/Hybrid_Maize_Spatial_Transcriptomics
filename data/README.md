# Data files

| File | Description |
| --- | --- |
| `SNPs.txt.gz` | Stringently called SNPs between the B73 v5 and Mo17 v2 genomes, used for genotype-aware allele assignment. |
| `lncRNA.gtf.gz` | lncRNA annotation generated from deep Kinnex long-read sequencing of embryo and endosperm tissues from B73 × Mo17 hybrid maize kernels at 14 days after pollination. |
